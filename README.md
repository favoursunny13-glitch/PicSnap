# PicSnap Playable Prototype

Phaser 3 CDN을 사용하는 정적 웹 퍼즐 게임 프로토타입입니다. 별도 빌드나 서버 애플리케이션은 필요하지 않습니다.

퍼즐은 화면 중앙의 고정된 3×3 보드 안에서 9개 조각의 시작 위치를 무작위로 섞어 생성합니다. 조각을 다른 칸으로 옮기면 해당 칸에 자동 정렬되고, 기존 조각과 위치가 교환됩니다.
연결되지 않은 조각은 둥근 모서리와 칸 사이 여백으로 구분됩니다. 정답 위치에서 서로 맞닿은 조각이 2개 이상이면 연결된 조각으로 표시되어 여백 없이 원본 이미지처럼 이어집니다.
스테이지 최초 셔플에서는 서로 맞는 조각이 우연히 연결되지 않습니다. 한 번 연결된 조각 중 하나를 드래그하면 연결 그룹 전체가 함께 이동하며, 놓은 위치의 칸에 그룹 단위로 자동 정렬됩니다.
클리어 표시는 현재 페이지를 사용하는 동안만 유지되며, 브라우저를 새로고침하면 모두 초기화됩니다.
스테이지 선택 화면의 미리보기는 클리어 전까지 약한 블러 효과로 표시됩니다. 스테이지를 클리어하면 해당 미리보기와 완료 화면에서 블러 없는 원본 이미지가 공개됩니다.
패션 사진의 디테일을 보존하기 위해 퍼즐 조각은 고정 저해상도로 축소하지 않고 원본 셀 해상도를 사용합니다. 이미지 스케일링에는 고품질 보간을 적용하며, 고해상도 화면에서는 성능을 고려해 최대 3배 HiDPI로 렌더링합니다.
텍스트는 모니터의 실제 전체 화면 해상도에 맞춰 최소 2배, 최대 3배 해상도의 전용 텍스처로 렌더링합니다. 4K 전체 화면에서도 글자가 확대 보간되지 않도록 캔버스 해상도를 자동 선택하며, 캔버스 전체 CSS 필터는 사용하지 않습니다.
스테이지 클리어 화면에서는 완성 이미지를 크게 표시합니다. 이미지 위에 커서를 올렸을 때는 그대로 보이며, 이미지를 누르는 순간에만 시스템 마우스 커서를 숨깁니다. 포인터 위치를 중심으로 원본이 0.2초에 걸쳐 2배까지 확대되고, 포인터를 놓으면 커서가 즉시 복원되면서 0.2초 동안 기본 배율로 부드럽게 축소됩니다.
각 스테이지에 진입하는 순간부터 클리어까지의 시간이 `분:초:밀리초` 형식으로 퍼즐 보드 위에 표시됩니다. 클리어 후 원본 이미지를 먼저 감상한 다음 `SAVE MY RECORD`를 선택하면 닉네임을 입력하고 해당 스테이지 랭킹을 확인할 수 있습니다. 메인 화면 우측 상단의 `VIEW RANKING`에서도 스테이지별 기록을 볼 수 있습니다. 현재 정적 GitHub Pages 버전의 랭킹은 브라우저의 로컬 저장소에 보관되므로 다른 기기나 브라우저와 공유되지 않습니다.
개발자용 랭킹 초기화는 메인 화면의 `VIEW RANKING` 패널이 열려 있을 때 Backquote 키(`)를 다른 키 없이 단독으로 누르면 실행됩니다. `Shift + Backquote(~)`와 `Ctrl`·`Alt`·`Meta` 조합은 무시합니다. 모든 스테이지의 로컬 랭킹이 삭제되고 현재 랭킹 표가 즉시 갱신되며, 실제 게임 화면에는 초기화 버튼이나 단축키 안내를 노출하지 않습니다.
랭킹 패널의 제목·탭·안내문·닉네임·시간은 별도의 최대 6배 고해상도 텍스트 텍스처로 렌더링되며, 스테이지 탭을 전환해 새 텍스트가 생성될 때도 같은 선명도 설정을 다시 적용합니다.
닉네임 입력 창이 열려 있는 동안에는 뒤쪽 게임 캔버스의 입력을 잠급니다. 창 바깥을 클릭하거나 모달의 버튼을 조작해도 완성 이미지의 확대 기능이 실행되지 않으며, 모달이 닫힌 다음 프레임에만 게임 입력이 복원됩니다.
좌우 원형 레일과 세로 타이포는 고정 16:9 캔버스가 아닌 전체 브라우저 화면의 반응형 장식 레이어에서 렌더링됩니다. 16:9에서는 원형에 가까운 비율을 유지하고, 울트라와이드에서는 여백 크기만큼 가로로 확장된 타원이 되어 선이 캔버스 경계에서 잘리지 않습니다. 세로형 화면에서는 게임 화면 높이에 맞춰 함께 축소되며 중앙 콘텐츠 영역으로 갈수록 투명하게 사라집니다. 페이지 진입 시 좌우 레일과 타이포가 순차적으로 활성화되고 장식 레이어는 포인터 입력을 받지 않습니다.
전체 UI는 블랙·일렉트릭 바이올렛·소프트 라벤더를 중심으로 한 프리미엄 패션 에디토리얼 스타일을 사용합니다. 글래스 패널, 앰비언트 글로우, 카드 시머·호버 모션, 연결 펄스, 클리어 리빌 플래시와 파티클 효과가 포함됩니다.
울트라와이드 및 다양한 모니터 비율에서는 16:9 게임 화면을 왜곡하지 않고, 남는 좌우 공간을 반응형 글로우·사이드 레일·메탈 엣지 프레임으로 자연스럽게 확장합니다.

## 실행

브라우저의 로컬 파일 제한을 피하려면 `D:\PicSnap`에서 정적 웹 서버를 실행한 뒤 접속하세요.

```powershell
python -m http.server 8000
```

그다음 `http://localhost:8000`을 엽니다.

## 실제 이미지 추가

현재 Stage 01과 Stage 02는 `assets/images`에 포함된 실제 이미지를 사용합니다.
`js/stage-images-v2.js`에도 같은 이미지가 데이터 형식으로 포함되어 있어 `file:///D:/PicSnap/index.html`을 직접 열 때도 로컬 이미지 로딩 제한 없이 표시됩니다.

1. 아래 파일을 추가합니다.
   - `assets/images/stage01.jpg`
   - `assets/images/stage02.jpg`
   - 필요 시 `stage03.jpg`부터 `stage06.jpg`까지 추가
2. `js/game.js`의 `STAGES` 항목에서 해당 스테이지의 `useBundledImage`를 `true`로 설정합니다.
3. 스테이지를 늘릴 때는 같은 데이터 형식으로 항목을 추가합니다.

이미지는 원본 가로세로 비율을 유지한 채 전체 영역이 3×3 조각으로 분할됩니다. 퍼즐 보드 테두리와 각 칸 크기도 이미지 비율에 맞춰 자동으로 변경됩니다.
